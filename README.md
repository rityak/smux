# smux

Мультиплексор потоков поверх прокси.

Форк [metacubex/smux](https://github.com/metacubex/smux) для [miray](https://github.com/rityak/miray). Наш код — в ветке `miray`.

## Что изменено

- Запись, брошенная по таймауту или закрытию сессии, больше не уходит в сеть позже из буфера, который уже переиспользован.
